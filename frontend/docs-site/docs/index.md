# Solvable AI documentation

> Customer-controlled AI infrastructure for models, data, agents, and spend.

Solvable gives teams one governed control plane for multi-provider AI. This documentation explains how to use the four portals, call the unified API, create and install marketplace agents, manage privacy and routing, and operate the platform safely.

| Start with | Use this when |
|---|---|
| [Platform introduction](platform/intro.md) | You want the product concept, architecture, and operating rules |
| [Portal overview](portals/overview.md) | You need User, Organization Admin, Platform Admin, or Agent Creator guidance |
| [API quickstart](api/quickstart.md) | You are integrating an application |
| [Generated API reference](api/reference.md) | You need exact endpoints, parameters, and responses |
| [Agent marketplace](marketplace/overview.md) | You want to discover or install governed agents |
| [Create an agent](creator/create-agent.md) | You want to publish an agent |

The API reference is regenerated from the live gateway OpenAPI contract during every documentation build. Markdown files in this repository remain the editable source of truth.
