# Discover and install agents

Search by job, category, language, publisher, supported model, price, or verification state. Open the preview before installing so you can inspect permissions, data policy, side effects, support contact, release version, and UZS pricing.

Organization Admin approves installation for a tenant or workspace. The install creates a tenant-scoped binding to an approved version and records the selected budget, roles, data sources, and allowed tools.

Users can run an installed agent within that binding. If the agent requests a permission outside the installed contract, the request is blocked and recorded as a policy decision.
