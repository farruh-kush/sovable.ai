# Agent Creator portal

Agent Creator is the publishing workspace for developers, agencies, and domain experts who want to distribute governed AI applications in the Solvable marketplace.

## What you publish

An agent package contains a signed manifest, display metadata, input and output contract, model policy, provider eligibility, tools, data scopes, side-effect level, test cases, release version, support contact, and commercial terms.

## The publishing path

1. **Define** the job the agent completes and the customer outcome.
2. **Declare permissions** for models, tools, network destinations, data classes, and side effects.
3. **Test** normal requests, malformed input, prompt injection, sensitive data, tool failure, and budget limits.
4. **Submit** the signed package for automated checks and human review.
5. **Release** an approved version to eligible organizations.

The Agent Creator portal never grants an agent permission to bypass the organization's masking, routing, budget, or audit policy.
