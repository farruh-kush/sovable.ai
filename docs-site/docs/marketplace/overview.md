# Agent marketplace

The marketplace is a governed application store for Solvable agents. It combines familiar discovery with explicit enterprise controls.

## Listing cards

A listing shows the agent name, publisher, verification state, category, supported languages, installations, release version, model policy, data policy, requested permissions, side-effect level, and price in UZS. A listing never hides an agent's tool or data requirements behind a generic install button.

## Review lifecycle

A creator submits a signed package. Automated checks validate the manifest, dependency graph, permissions, code and artifact security, test evidence, and policy compatibility. Human review evaluates quality, safety, privacy, licensing, supportability, and commercial terms. Only an approved release becomes installable.

## Safe defaults

An organization may preview an agent, install it for a selected workspace, limit it to selected roles, configure a budget, and revoke it. An installation inherits tenant masking and routing policy. Agent runs are auditable and can be disabled without deleting historical evidence.
